Treat a stylesheet import `no-unknown-classes` cannot read in Angular styles as it treats an unreadable selector: an import that does not resolve, one written with webpack's `~`, or more than 64 stylesheets in all settle every class and are said once, instead of leaving the classes they declare unknown. A package import also resolves through what the package's `exports` give a stylesheet under `style`.
