Judge an Angular `*Class` input in `no-restyle` by the contract of the directive that takes it, read from the project's own decorators, then from the `.d.ts` of an installed library (the `ɵɵComponentDeclaration`, `ɵɵDirectiveDeclaration` and `ɵɵNgModuleDeclaration` Angular 19 to 22 write), else taken for the component a contract names by its tag. A component an NgModule declares uses what that module can, found in its directory or the ones above it. Lists and selectors written as constants are followed; a decorator holding what cannot be read, a spread or a computed key, leaves the input to the tag. A `.d.ts` none of whose declarations can be read is said once per package.
