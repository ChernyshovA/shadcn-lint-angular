In Angular code, read what an arrow function passed to a `mergeFunctions` helper returns, such as spartan's `classes(() => "p-4")`, and of a helper named `classes` only the first argument: spartan's takes its options second. Angular code is a template, a script that imports from `@angular/`, or another script of an Angular project; elsewhere helpers are read as before.
